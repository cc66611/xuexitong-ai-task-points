# 用户教程：选择你的 AI

本教程参考源码提供者保留的 [原 README](UPSTREAM_README.md)、[安装说明](INSTALL.md)、[使用指南](GUIDE.md) 与 [原 WorkBuddy 教程](UPSTREAM_WORKBUDDY.md)，按多 AI 仅任务点版本重新整理。

## 1. 安装完整项目和一份脚本

下载并解压完整源码 ZIP，根目录应有 `package.json`、`src/`、`vendor/`、`assets/`、`dist/`。浏览器需要 Tampermonkey（篡改猴）。

打开油猴 → 管理面板 → 实用工具 → 从文件导入，按接入方式选一个文件：

- 不确定以后用什么：`dist/xuexitong-task-points-only.user.js`（通用版）。
- 用 ChatGPT / Codex 账号：`dist/xuexitong-codex.user.js`。
- 用 WorkBuddy / CodeBuddy 账号：`dist/xuexitong-workbuddy.user.js`。
- 用 API Key 或第三方网关：`dist/xuexitong-api.user.js`。

只启用一份。各文件保留相同名称和命名空间，方便覆盖更新并保留设置；版本区别仅为首次打开的预设，已有接口配置优先。所有版本都保留全部 AI 适配器和同一套仅任务点逻辑。私有仓库建议下载 ZIP 后从文件导入，Raw 链接可能无法被油猴直接获取。

安装后刷新具体学习通章节或作业页，核对面板显示 **1.7.7.8**。下载或安装完成不代表旧标签已经更新，必须刷新。

## 2. 连接自己的 AI

**Codex 账号版：** 按 [Codex 教程](CODEX.md) 安装官方 CLI、本人登录，再双击 `启动Codex助手.cmd`。面板使用本地 Codex、`http://127.0.0.1:18763` 和 `src/local/bridge-token.txt` 中的本地连接码；模型和思考强度在服务启动菜单选。

**WorkBuddy / CodeBuddy 账号版：** 按 [WorkBuddy 教程](WORKBUDDY.md) 安装官方 CodeBuddy CLI、登录与 WorkBuddy 相同站点和账号，再双击 `启动WorkBuddy助手.cmd`。面板使用本地 CodeBuddy / WorkBuddy、`http://127.0.0.1:18764` 和 `src/local/codebuddy-token.txt` 中的连接码。

**API 版：** 按 [API 教程](API.md) 选服务商，填自己的 Base URL、完整模型 ID、API Key。OpenAI、Claude、Gemini 和已有国内服务商预设都保留，不需要启动本项目本地服务。

Windows 的 `启动学习通助手.cmd` 提供 Codex、WorkBuddy 和 API 使用菜单。CLI 服务需要 Node.js 22 或更高版本；Windows 使用 `npm.cmd` 可避开 `npm.ps1` 执行策略问题。所有本机登录、连接码与模型偏好都放在忽略的 `src/local/`，不能上传。

## 3. 文字和图片分别测试

面板 → 接口 → 添加 / 编辑接口，选择用途“文字题”“图片题”或“文字题＋图片题”，保存后点“测试 AI”。可以把一个 AI 用于文字，另一个用于图片，也可以同一配置兼用。

图片题需要模型与接口实际支持图片。文字测试通过不代表图片也通过；Codex/WorkBuddy 使用的是各自 CLI 的账号用量，API 版使用的是 API 提供方用量。本地连接码不是 API Key，WorkBuddy 与 Codex 的端口和连接码也不能混用。

先点“预览 AI 答案”，确认题干、公共材料和每道子题返回完整。测试、预览和作答都可能使用账号用量，具体以本人账号权限和用量明细为准。

## 4. 仅任务点与作业

**章节：** 打开具体章节后开始。已完成任务点优先跳过，不等待已完成视频建立播放器，不为了满分重做；加载稳定后确认无任务点的内容才跳过。目录明确待完成但页面无法识别时暂停。标题末尾 `*` 不代替任务点判断。

**独立作业：** 手动打开当前作业并选“作业”。先预览，再决定是否作答。作答后可选择不提交、暂时保存或直接提交；直接提交需要允许 AI 回答主观题。作业模式不自动打开下一份作业。

**题型：** 支持已适配控件的单选、多选、判断、填空、简答、排序、连线和阅读/完形/组合子题；图片、公式走图片用途。特殊富文本、上传附件和未适配控件可能需要人工处理。已有人工输入、请求期间的修改会保护，不通过删除校验来强填。

保持课程页在前台，不最小化浏览器。预览只显示答案，不填写、不点击保存或提交。完成提示和模型置信度不代表平台已经判分。

## 5. 更新和排错

更新前停止脚本与 CLI 服务；下载完整新版，保留自己的 `src/local/`，覆盖更新油猴并刷新。不要把别人的登录缓存或连接码复制到自己的机器。只安装一个版本，不同时启用多个学习助手。

- 找不到 `package.json`：在完整项目根目录启动，或使用根目录 `.cmd`。
- 401：API 版核对 Key；CLI 版核对当前这份服务的连接码。
- 409：上一轮仍在处理，等待或点停止，不要多页面同时发起。
- 422 / 答案格式错误：检查用途、图片和模型返回；CLI 对异常文本最多修正一次，仍失败停止。
- WorkBuddy 图片失败：另配已验证的图片接口；不能只凭文字成功推断图片能力。
- 面板还是旧版：确认油猴覆盖成功，再刷新原课程标签核对版本。
- 端口冲突：Codex 默认 18763、WorkBuddy 默认 18764；可选本地脚本安装服务使用 18765，避免与 WorkBuddy 冲突。

继续排错请读 [Agent 教程](AGENT_GUIDE.md)。原作者完整说明仍保留在 docs 中，但其历史版本、安装链接或更新策略不覆盖本仓库说明。
