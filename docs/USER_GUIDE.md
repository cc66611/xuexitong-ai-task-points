# 用户教程

本教程参考源码提供者保留的 [安装说明](INSTALL.md)、[使用指南](GUIDE.md) 和 [原 README](UPSTREAM_README.md)，按本仓库的仅任务点版本重新整理。先完成一次安装，以后只需启动服务。

## 1. 准备环境

需要 Edge 或 Chrome、Tampermonkey（篡改猴）、Node.js 22 或更高版本，以及 Codex CLI。

终端中检查：

```powershell
node --version
npm.cmd --version
codex --version
```

尚未安装 Codex CLI 时，可使用 npm 安装：

```powershell
npm.cmd install -g @openai/codex
codex login
codex login status
```

登录时选择自己的 ChatGPT 账号并在浏览器完成登录。本项目沿用 CLI 当前登录方式；要使用账号套餐而不是 API 计费，应确认 CLI 用的是 ChatGPT 登录，而不是 API Key 登录。套餐资格、可用模型和用量以账号实际显示为准。参考 [OpenAI Docs：CLI](https://developers.openai.com/codex/cli) 和 [身份验证](https://developers.openai.com/codex/auth)。已经能正常运行的 CLI 不必仅为下载本仓库而升级。

macOS / Linux 使用 `npm`，Windows 下文使用 `npm.cmd`，可避免 PowerShell 的 `npm.ps1` 执行策略问题。

## 2. 下载完整项目，安装油猴脚本

1. 从本仓库的 Code → Download ZIP 下载并解压。保留整个文件夹，确认根目录能看到 `package.json`。
2. 打开油猴 → 管理面板 → 实用工具 → 从文件导入，选择 `dist/xuexitong-task-points-only.user.js`，确认安装或更新。
3. 刷新一个具体学习通章节或作业页，面板应显示 **1.7.7.7** 和仅任务点说明。

更新现有安装时覆盖原脚本，不要同时启用两份。脚本名称与命名空间保留，正常覆盖可继续使用原来的油猴配置。仅下载文件不会更新已经打开的课程页，安装后一定要刷新。

私有仓库的 Raw 链接未必能被油猴直接获取；下载 ZIP 后从文件导入最稳定。`dist/xuexitong-ai-assistant.user.js` 是兼容文件，同样是仅任务点版，任选一个安装即可。

## 3. 启动本地 Codex 服务

Windows 推荐双击项目根目录的 **`启动学习通助手.cmd`**。它从自身所在文件夹启动，不依赖桌面上的固定路径。若创建快捷方式，让快捷方式指向此文件即可，不要只把启动文件移出项目目录。

也可以在项目根目录终端运行：

```powershell
npm.cmd run start:codex
```

选择账号可用的模型和思考强度，然后保持服务窗口打开。Windows 下若提示找不到 Codex，优先使用上述 `.cmd`；使用自定义安装位置时，把原生 `codex.exe` 的路径填入环境变量 `XXT_CODEX_BIN`。

首次启动会在 `src/local/bridge-token.txt` 自动生成本地连接码。整个 `src/local/` 仅属于你的电脑，不要上传、公开或发给其他人。

## 4. 配置文字和图片接口

在具体章节或作业页打开面板 → 接口 → 添加 / 编辑接口，填写：

- 服务商、接口协议：都选 **本地 Codex**。
- Base URL：`http://127.0.0.1:18763`，不加 `/solve` 等接口路径。
- API Key / 本地连接码：复制当前项目 `src/local/bridge-token.txt` 中的完整一行。
- 用途：选 **文字题＋图片题**，然后保存。

这里填写的是本机访问凭证，不是 OpenAI API Key。只配置文字用途会导致看图题不能走图片接口。

点击 **测试 AI**，确认文字、图片两项都通过，再点 **预览 AI 答案**。测试和预览会使用 CLI 已登录账号的用量；模型与思考强度由服务窗口控制，面板不会覆盖它们。

## 5. 使用章节和作业

**章节模式：** 打开具体章节，点击“开始自动”。只处理有未完成任务点标记的内容；已完成内容优先跳过，不等待已完成视频建立播放器，不为了满分重做。加载稳定后确认无任务点的内容才跳过；目录显示待完成但无法识别时会暂停。标题末尾 `*` 只是课程说明，不代替平台任务点判断。

**作业模式：** 手动打开一份未提交作业，点击“作业”。先预览答案，再决定是否作答。作答后可选择不提交、暂时保存或直接提交；默认不额外保存或提交。选择直接提交需要允许 AI 回答主观题。独立作业不会自动切到下一份。

**题型范围：** 单选、多选、判断、填空、简答，以及已适配控件的排序、连线、阅读/完形和组合子题。组合题会按子题处理，截图保留公共材料；图片、公式需要实际可用的图片接口。附件上传、未适配的富文本或特殊控件不保证可处理，遇到明确提示先停下来核对。已有人工输入会保留。

保持课程页在前台，不最小化浏览器。停止按钮用于取消当前请求和后续操作。预览只显示答案，不填写、不点击保存或提交；平台自身的保存行为由平台决定。

## 6. 换模型、更新、日常启动

- 换模型或思考强度：服务窗口 `Ctrl+C` 停止，再启动并重新选择。连接码、端口不变时不必重填接口。
- 更新：关闭本地服务，解压新版到新文件夹；需要保留原连接码和菜单选择时，只把自己的旧 `src/local/` 复制到新版 `src/local/`。再覆盖更新油猴脚本、刷新课程页、重启服务并测试。
- 下次使用：保留项目文件夹，先启动服务，再打开课程。不需要重复安装依赖或重新复制连接码。

## 常见问题

- **找不到 package.json / ENOENT：** 进入有 `package.json` 的项目根目录，或使用根目录启动文件。
- **401：** 核对当前这份服务的连接码，旧文件夹的码可能不同。
- **409 / 服务忙：** 等上一轮完成或点停止，不要同时在多个页面发起答题。
- **422 / 文本答案不完整：** 模型输出与输入框不匹配。服务仅对有问题的文本子题修正一次，仍失败会停止；先检查预览、图片用途和题图是否完整，不要连续提交碰运气。
- **选项无效或重复：** 先核对面板版本，更新后刷新；仍有问题时按 Agent 教程采集脱敏结构。
- **面板没变成新版：** 油猴确认更新后刷新原课程标签，核对面板版本，不以更新页标题作为成功依据。
- **端口被占用：** 检查是否已有服务，不要重复启动。可选的本地脚本安装服务使用 18764，与可选 WorkBuddy 的默认端口冲突，二者不要同时启动。

源码、测试与构建文件完整保留。更多原版设置见 [上游安装说明](INSTALL.md)，定制版的行为优先以本教程为准。完成提示、AI 置信度和预览成功都不代表平台成绩已经确认。
