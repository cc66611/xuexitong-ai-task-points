# 标签页静音

从本地候选 1.5.11 起，“静音播放”优先将**当前浏览器标签页**静音，效果相当于使用浏览器的“将此标签页静音”操作（例如 Edge 的 Ctrl+M）。脚本调用油猴提供的接口，不向电脑发送快捷键，不影响其他标签页或系统总音量。

## 安装与使用

1. 用本地候选脚本覆盖油猴中的旧脚本，保存。如果安装界面提示新增 `GM_audio` 权限，它用于读取、设置和监听当前标签页静音状态。
2. 刷新课程页，确认面板版本为 1.5.11。“静音播放”的勾选状态沿用原设置，默认开启。
3. 面板显示“已确认浏览器标签页静音”后，浏览器标签上的静音图标应出现。此时脚本解除播放器的静音，由浏览器负责拦截声音。播放器音量数值不被修改。
4. 取消勾选时，只撤销本次脚本自行设置的标签页静音；原来手动设置的标签页静音会保留。需要时可用浏览器菜单手动恢复声音。

## 无法使用时

需要油猴和浏览器支持 `GM_audio`。其他脚本管理器或旧版本可能没有该接口。未得到成功确认、接口失败或超时时，脚本保留播放器静音，并显示降级提示，避免突然出声。可以更新油猴后刷新，或重新勾选尝试。

停止脚本、夜间休息、人工验证和离开页面都不会为了恢复声音而主动取消标签页静音。修改静音不启动媒体，也不恢复已停止的任务。若用户手动解除标签页静音，脚本保留播放器静音保护，不持续与手动操作争夺标签状态。

浏览器仍可能拒绝有声媒体的自动播放。遇到提示时手动点击原生播放按钮；标签页静音不等于绕过自动播放限制，也不能保证后台运行或平台认可学习时间。

接口依据：[Tampermonkey 官方 GM_audio 文档](https://www.tampermonkey.net/documentation.php?locale=zh#api:GM_audio.setMute)。本次自动化回归模拟该接口并使用原生媒体元素；真实油猴授权、实际声音输出及课程任务点仍须安装后核对。
