# 作业模式（1.7.4）

本功能已随1.7.4发布。通过README中的安装入口更新，刷新作业页确认版本。作业面板保留开发测试提示与反馈入口，使用范围和实际结果仍需用户核对。

## 如何使用

1. 在课程的“作业”中手动打开一份未提交作业，保持页面在前台。
2. 在面板顶部连体开关选择“作业”。章节模式保留原有流程；考试为禁用占位，提示“在更新计划中”。
3. 配置自己的文字和图片接口。含图片或公式图片的题目需要图片接口，缺少配置时会提示。
4. 选择主观题和收尾方式，点击“作答当前作业”。首次安装默认“简答题不回答”和“作业作答后不提交”，保留主观题原有内容，完成客观题后不额外点击保存或提交。

“简答题由AI回答并填入”也包含已适配的计算题、论述题。选择后才允许选“作业作答后直接提交”；改回不回答时，直接提交禁用，并恢复不提交。另可选“作业作答后暂时保存”。这些设置保存在本机。

“不提交”表示脚本不额外点击平台按钮；平台自身是否自动保存，由平台决定。脚本只处理当前作业，不自动进入下一份。

## 预览和复查

“预览 AI 答案”显示答案，不填入、不保存、不提交。“复查AI作答”每次重新调用接口，与页面当前作答比较，显示一致、不一致和无法比较的数量，并逐题列出题号与内容。可多次复查，不替换已有答案。主观题不回答时，复查也跳过主观题。

客观题比较忽略多选顺序；文字忽略空白差异。主观题语义相同但措辞不同仍可能显示不一致。一致仅说明两次结果相同，不保证答案正确或满分。预览、作答和复查都可能产生接口费用。

## 当前适配范围

真实采集包含判断题、计算题、UEditor编辑区、暂时保存/提交按钮及五个编辑器的运行元数据。新增真实采集的文字单选和多选题结构，多选选项标记为 `num_option_dx`；1.7.6 可读取对应题型与选项。页面外层、选项点击处理、模型和平台回执仍为模拟，尚未在该用户真实作业上验证填写、保存、提交或成绩。普通文字填空支持范围仍以既有结构为准。

选词拖拽填空、共用文章和多个子题的阅读理解仍等待对应结构，未宣称适配。遇到未适配题型或缺少可用答案，本轮停止填写及收尾，避免缺题直接提交。章节已有题型的支持范围不受此说明替代。

## 停止与结果确认

请求期间人工修改、切换模式/接口/作业、离开前台、出现已识别人工验证、进入夜间休息或按停止，都会取消旧请求及后续操作；不会自动续填或续交。已有不同作答或人工草稿保留。

保存、提交分别点击页面原有按钮；只有观察到本次新出现的可识别成功提示才报告确认。结果未知会提示人工检查；发起提交前写入本机防重记录，刷新也不自动重交。未知确认窗口请停止后反馈局部结构，不需要为了采集特意提交。

## 验证边界

真实DOM和运行元数据用于确定结构；自动回归使用脱敏结构、隔离浏览器、模拟模型、模拟编辑器和平台回执。尚未完成真实作业填写、真实暂存/提交、付费模型推理或实际成绩验证。最终测试数量和安装摘要以本地验收报告为准。

## 1.5.13 状态显示修补

修复作业页浅灰pre背景造成状态白条；入口限制原因直接显示在运行状态，图片准备显示进度。后台、人工验证或缺少配置时仍会阻止相应动作，不因修补解除保护。关闭F12后再点击，防止开发者工具占用焦点。
