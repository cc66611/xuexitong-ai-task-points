# 1.7.0 面板动效

面板保留原有功能与紧凑对齐。动效只表达真实的界面变化，不代表模型速度、任务点完成或实际成绩；“更多”里可关闭界面动效，系统减少动态效果设置优先。

本轮逐项评估了用户提供的两组共18种交互。没有为了展示效果新增删除任务、自动设置或伪进度。

| 参考交互 | 适配结论 | 面板处理 |
| --- | --- | --- |
| 圆形主题切换 | 采用 | 鼠标/触摸主动切主题时从触点揭示，240ms；自动模型主题与键盘即时切换，旧过渡可取消。 |
| 拖拽排序 | 本轮不采用 | 课程队列保留既有上移/下移和顺序规则，避免UI升级改变运行中队列。 |
| 批量勾选交错 | 暂不采用 | 当前没有可靠的批量选择入口，不为动画虚构批量操作。 |
| 滑杆惯性吸附 | 不采用 | 倍速保留原生离散选项，不改成容易误操作的滑杆。 |
| 文本/设置展开 | 采用 | 原生details测量高度，180ms，反向点击从当前高度接续；键盘即时。 |
| 步骤条弹簧 | 简化采用状态反馈 | 只在真实状态类别变化时点亮状态徽标，不伪造完成百分比，也不跟随秒数反复播放。 |
| 关联开关反馈 | 采用 | 真实选择完成后局部轻微回响，160ms，不代替用户切换其他开关。 |
| 卡片弧线删除 | 不采用 | 不给学习记录、课程或待复核条目增加滑删风险。 |
| 卡片堆叠滚动 | 不采用 | 长记录和设置保持平面阅读，避免遮挡与阅读错位。 |
| 标签扩张选择 | 改为稳定选中指示 | 选中背景移动，标签本体和命中区域不变，不重犯按钮错位。 |
| 磁吸效果 | 限定装饰层 | 仅标题图标最多1px随指针移动，不吸走开始/停止按钮。 |
| 速度形变 | 不采用 | 不扭曲文字、输入框和面板，避免拖动时可读性下降。 |
| 分层视差 | 采用 | 背景插画最多约1.5px反向位移；仅精细鼠标指针，触摸与减少动态效果时关闭。 |
| 中心聚焦缩放 | 不采用整面板缩放 | 保持用户正在读取/操作区域的尺寸稳定，状态徽标仅有极轻微反馈。 |
| 液态Tab | 采用 | 160ms选中指示与短内容进入，快速反向选择可接续；键盘即时。 |
| 图片展开 | 暂不采用 | 保留现有预览，不在本轮添加新的图片弹窗或复制题目节点。 |
| 手势转场 | 限制采用已有工作区切换 | 点击时160ms过渡，保留移动端原生滚动；不接管左右滑动或课程导航手势。 |
| 碰撞弹挤回弹 | 不采用 | 保留已有面板边界约束，不把业务界面做成物理玩具。 |

## 动效配方与保护

- 复用已有 `--ease-out`，曲线为 `cubic-bezier(.23,1,.32,1)`；小反馈140–160ms、展开180ms、现有弹窗200ms、主题240ms。
- 使用CSS transition与原生WAAPI；除折叠高度测量外，运动限于transform、opacity与主题clip-path，没有引入动画库。
- 设置/按钮节点及其业务处理器保持原身份。没有额外模型请求、自动保存、提交、开始或切章。
- 无后台常驻动画循环；装饰只在指针移动时申请单次帧，离开恢复，pagehide清理。
- 键盘触发不播放过渡；快速展开/收起、切主题与切区可以中断。减少动态效果时按钮即时反馈，取消几何运动。
- 不支持View Transitions的浏览器即时切主题。关闭动效也不影响设置持久化和功能执行。

桌面、390窄屏、减少动态效果、键盘及快速反向操作的测试属于隔离浏览器验证；真实课程效果与成绩另行核对。
