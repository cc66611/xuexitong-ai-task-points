# 题型兼容更新 1.7.7.3

核对日期：2026-10-31。比较基于固定提交的源码，不把“识别题型名称”算成能填写，也不把模拟验证当成真实课程已判分。

## 原来的缺口与本次更新

- 排序题：原来直接报不支持。现在支持用户当前章节里的 `.sortQuesOption` + `.sortQuesSelect select`，包括 Chosen 外观，以及新版作业的 `.selectBox.order_box`。模型返回完整的编号排列；保留从左到右的顺序，核验界面、原生选中值和提交字段。纯拖拽而无这些控件的页面仍需单独适配。
- 连线/匹配题：原来不支持。现在按左、右两组显示编号生成题目，支持原生/Chosen 下拉框和 `.line_answer_ct .selectBox` 自定义下拉框；把显示编号转换为平台内部编号，检查隐藏答案字段。允许多个左侧对应同一右侧。没有可靠映射或内部编号冲突时暂停。
- 阅读理解：原来不能稳定拆分复合题。现在把 `.reading_answer` 分成独立子题，每题保留公共材料；支持能够核验 native/ARIA 选中状态的选择控件。需要截图时截取包含公共材料的整个父题，避免只截子题遗漏材料。
- 完形/完型填空：现在拆分 `.filling_answer` 子题，支持可核验选择控件及普通文本输入框。无明确选中状态、富文本子题结构尚未适配时暂停。
- 名词解释、计算、资料、翻译、写作、问答、作文、证明题：原来部分题型标签没有映射。章节页现在映射到现有文本作答流程，沿用已有简答题“提交/保存/跳过”设置、已有输入保护和语言规则。新版作业沿用已验证的单 UEditor 合同。
- 分录题：章节页支持单文本框及多普通文本框的顺序填写；多框采用完整截图提供字段标签。复杂借贷表格和特殊编辑器不能据此声称完全兼容。

单选、多选、判断、填空、简答、论述，以及 1.7.7.2 修复的公式图片选项继续保留。仅处理未完成任务点、遇到无法确认的归属时暂停、完成后不为满分重做的规则继续生效。

## 仍然不能承诺覆盖的内容

参考扩展还有部分编程编辑器的填写处理，本版未添加 Monaco、CodeMirror 等程序题编辑器，也未添加执行代码、绘图/上传作答、原生音频理解或任意拖拽组件。题型名相同、控件不同的页面仍需实际结构适配。主观题正确性和批阅结果由模型能力与平台决定。

## 安装和验证

油猴安装版本为 1.7.7.3，脚本面板现在也会显示完整定制版本。正常覆盖原脚本会保留接口配置；不要同时启用多份学习助手。更新后刷新课程页，再核对版本和“仅任务点模式”。本地 Codex 桥接服务必须也加载新题型，服务 `/health` 中提供 `supportedQuestionTypes` 便于核验。

本次新增测试在独立无头浏览器中使用模拟页面及模拟平台事件，验证原生/Chosen 和自定义排序、连线、编号重排、已有输入保护、无效排列、停止取消、阅读公共材料及子题、完形文本框和扩展标签；另验证完整的排序模型响应→填入→提交字段同步→任务点完成流程。真实课程未用于提交测试。
