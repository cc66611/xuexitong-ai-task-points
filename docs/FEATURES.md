## 1.5.9 简答题：按整份测验处理

面板增加三个互斥按钮：简答题直接提交、简答题暂时保存、简答题直接跳过。选中的按钮凹下，其他按钮弹起；首次使用和无效旧设置默认暂时保存，已保存的明确选择不强制更改。修改设置会停止旧操作，需要显式开始。

暂存或跳过的测验写入“跳过记录”，包含题目总数、简答题数量和题号、原题型与处理原因。暂存成功仅表示答案已保存，未提交、未证明平台任务点完成或得分。保存结果不明保留待复核，不重复保存、刷新重试或改为提交。缺失/禁用/重复保存入口不会回退提交。已在非满分成绩页时，暂存/跳过设置保留当前成绩，不自动重做。

## 1.5.8 讨论题

# 功能说明

## 1.4.10 大题量与任务接续

勾选静音时，对延迟加载、停止后手动播放和播放器重置的视频继续同步静音；不因同步静音而自动播放。取消脚本静音后，不反复覆盖原生播放器的手动静音。

开始前已经完成的音视频直接接续，不因播放器恢复进度或原生自动播放而重播整段；只有本轮由脚本启动的音视频在播放途中提前变绿时，仍等待自然结束。显式重新开始会重新核对平台完成状态。

单页上限提高到256题；文字每批最多16题，图片每批最多8题，仍按约12000个序列化字符提前拆批。文献先检查自身平台任务容器，已完成的不再打开或计时阅读；同页未完成和无任务点的资料仍分别处理。接口测试结束释放请求状态，显式开始立即核对任务；停止取消继续有效。

## 1.4.8 音频任务与静音

识别已适配的音频播放器与各自任务点，同页多段按顺序自然播放，排除隐藏的空音频。播完后核对平台对应任务点，未结算时显示等待，不修改完成标记。无需接入 AI，沿用静音、倍速、手动停止和夜间休息；静音偏好也应用于音频手动重播。平台时长是否被接受以任务点显示为准。

## 1.4.3 运行状态刷新优化

状态提示与跳过记录保持不变时不再重复重建；配置、夜间状态、待复核总数与最近20条记录分别核对，有变化时及时更新。原有答题、停止取消、任务接续与主题外观保持一致。

## 1.4.2 填空与同章多测验

提交确认后保留提交状态；成绩尚未显示时先等待，30秒后自动刷新一次测验子页，再等待至多60秒，不再次点击提交。测验框架加载时保留当前章节等待，手动停止会取消后续刷新。

未满分且页面有唯一可用重做按钮时继续重做；即使按钮没有标出剩余次数也可使用，平台明确显示0次时才停止重做。重做优先采用平台提供且能逐题逐空匹配的标准答案原文，同一未更新成绩页不会反复点击。没有重做入口时保留实际成绩继续，不把它写成满分。

同一章节的课前测、课后测按各自测验ID独立保存答案、成绩和提交状态。前测已完成时仍继续后测，两个任务都核对后才继续章节。完整可读的填空答案先提交，再按实际成绩与平台正确答案处理重做；低置信度不再单独拦住整页。

## 1.4.1 界面与使用引导

AI 主题保持背景透图，操作按钮紧接正文顶部；奶龙、奶蛙使用清理过的透明人物并关闭外部灰色投影。主题图鉴展示九种实际脚本界面，截图大小一致，原角色设计作者注明为 ZipZipPipe。

打开更新页前后均提示等待油猴加载，可能需要约一分钟或更久；中转页保留等待确认窗口，数分钟无响应再按备用步骤操作。本地 Codex 的连接码输入框分行说明下载、菜单选择与连接码步骤，教程直接定位到本地连接章节；已保存的本地接口卡片说明服务窗口关闭后暂不可用，重启原服务即可恢复，地址或连接码变化时需更新配置。测试结果居于可视区域中央，不加黑色遮罩，保留原页面背景。

模型返回可读、逐空完整的填空/简答候选后，即使自评置信度较低也先填写作答，不因这一项拦住整页；随后依据实际得分和平台正确答案重做。仍拒绝空答案、空位数量不匹配或明确无法读清的内容，不随机编造文字。

## 1.4.0 课程填空题

按真实课程的 Zy_ulTk / blankItemDiv / InpDIV 与 UEditor 结构绑定每个空位。只使用页面已有编辑器，调用 setContent、contentChange 和 sync，核对预览、编辑器与提交 textarea。支持多题、多空及延迟初始化；普通输入框和简答继续适用。未知富文本结构不套用此适配。

先提交 AI 答案，再读取实际分数；已完成标记不作为满分证据。平台明确给出正确答案并允许重做时，保留每空原文再填一次；多空要求“第N空”或明确数字顺序，不能可靠匹配时不猜。参考答案已失败的整组不重复提交。无参考答案沿用原有得分历史逻辑，文本不随机生成候选。

保护初始内容、请求中及填写过程中的手动修改；编辑器等待最多4秒，停止/夜间/切页取消旧操作。无法处理时仍由原有恢复与跳过策略接续，不宣称跳过已完成。


## 文字题、接口管理与运行提示

- **文字题不要求视觉模型**：正常题干/选项直接发文字；忽略操作按钮里的装饰图标。对页面的替换字体，先用校验过的字形字典恢复请求中的文字，不改写课程网页。真正图片、公式或还原失败的内容保留截图流程。字体格式、字典不匹配或网络失败时不能保证纯文字作答。
- **保存多个接口**：“保存设置”既保存当前用途，也保存一份可复用接口。展开“已保存接口”可查看服务商、模型 ID、地址主机、协议、遮挡后的密钥、保存时间和最近成功调用时间；最多 30 组。同一地址/模型/密钥再次保存会更新原配置，换模型或密钥会新增一组。“用于文字/图片”会切换设置并停止当前运行，需要重新测试后手动开始。
- **清除与删除**：“清除密钥”会移除当前对应的本地接口记录，并清除文字/图片用途里同一配置的密钥；其他已保存接口不受影响。“删除配置”也是本地删除，不会撤销服务商的 API Key。密钥保存在油猴存储里，不是加密保险箱，详见[隐私说明](SECURITY.md)。
- **状态卡和失败提示**：三主题使用各自配色，状态文字用独立字体自动换行。AI 请求失败时，下方提示保留 60 秒并倒计时，后续状态不会覆盖它；同一轮自动恢复不反复延长时间。手动测试或重新开始可再次提示。失败不代表一定没填 Key，也可能是地址、模型、网络、额度或响应内容问题。
- **图片识别结果弹窗**：识别随机数字后，明确显示通过/未通过，关闭后焦点回到测试按钮。角色做一次短动效，可在设置中关闭；系统减少动态效果或键盘操作时不播装饰动画。不自动启动课程，不把取消测试当成失败。
- **版本提醒**：手动检查，或启用且被浏览器识别为 WLAN 的自动检查发现新版本后，顶部显示更新横幅。× 关闭该版本提示；“稍后提醒”延后 6 小时，之后检查时可再显示。关闭不影响“脚本更新”里的更新入口；新版本可再次提示。脚本不自行覆盖已安装代码、刷新课程或中断当前运行。


## 不接入 AI，也能做什么？

**不需要 API Key，也不用先点“测试 AI”。** 安装后在面板的“运行模式”选择 **不接入 AI**，直接点击 **开始自动**。没有保存 Key 的用户默认使用此模式；已配置过接口的用户保留 AI 模式，也可随时切换。切换会停止当前运行，确认后再点“开始自动”；已有模型和 Key 会保留。

| 内容 | 不接入 AI 时的行为 |
| --- | --- |
| 视频 | 逐个播放可识别的视频，保留倍速、静音、播放报错切线、播完后等待任务点结算和一次重播恢复 |
| PDF / Word 等文献 | 打开已适配的预览，停留 30 秒后关闭并继续；只能处理能识别的文件入口和预览 |
| 专题阅读 | 按已适配目录逐项打开，每项累计前台、有焦点的 90 秒；切走或夜间休息时暂停 |
| 章节学习检测 | 不选择答案、不提交、不重做；记录待复核后，继续本章剩余内容或下一节。已有全对成绩页可以继续 |
| 视频内弹题 | 已有可用的“继续学习”按钮时点击继续；仍需作答且挡住播放时，记录并跳过受阻视频，尝试处理其他视频、阅读和后续章节 |
| 未识别或处理失败的内容 | 记录后尝试继续，不因缺少 AI 配置重复测试接口；无可用导航时提示手动接手 |
| 其他设置 | 保留夜间休息、停止、主题、跳过记录、干扰窗口关闭和脚本更新入口；“测试 AI”“预览 AI 答案”在此模式禁用 |

此模式不发送模型请求，也不生成题目截图供模型分析。课程本身、文档加载和手动/自动检查脚本更新仍可能联网，因此它不是离线模式。**跳过不等于完成：被跳过的测验、弹题受阻的视频及未结算任务点仍可能是未完成状态。** 运行结束后请查看“跳过记录”，自行补做。平台没有提供可用的下一步、强制回看、验证码和账号异常等情况仍需手动处理，不能保证整门课程全部完成。

需要自动作答时，将运行模式改为 **接入 AI（自动答题）**，配置或核对接口，保存并测试后再开始。


本文介绍 **1.0.14** 的功能、操作顺序和使用限制。安装步骤见 [安装教程](INSTALL.md)，接口地址和模型参数见 [模型配置](PROVIDERS.md)。

## 脚本更新

支持油猴自身检查更新，也可展开面板“脚本更新”手动检查。开启“仅 WLAN 自动检查”后，明确识别为 WLAN、在线且页面可见时，每 2 小时最多尝试一次；无法识别连接类型时保留手动检查，不把网络质量 4g 当作 WLAN。该开关不控制油猴独立的后台更新计划。

发现新版后可点击按钮打开油猴更新页，安装需在油猴确认；无法打开时提供管理面板操作步骤和 ZIP 备用方式。升级后刷新课程页，自动展开当前版本的本次说明，不显示以前版本内容；点击“知道了”收起。检查失败不停止课程流程。详见[更新教程](UPDATES.md)。

## 当前页失败后怎样重试

本节的自动测试与重启适用于 AI 模式；无 AI 模式直接记录无法处理项并继续，不会测试接口。

多层 iframe 的测验会关联到它实际所属的祖先任务容器。截图或题目处理失败时，当前章节仍先恢复一次；再次失败则把测验及其所属待处理标记一同列为待复核，继续可处理的内容或下一节，不再对已跳过的同一项持续等待。跳过不修改平台标记，也不表示测验通过。

如果问题已手动排除，可显式点击“开始自动”，重新尝试当前页失败或跳过的内容；当前章的一次自动恢复预算也会重置。历史记录保留，因此仍可在“跳过记录”中看到先前失败。自动恢复内部的重新开始不会不断重置自己的预算；停止、预览 AI 答案与夜间规则保持。

本次修复的是错误发生后的恢复路径，没有确认或解决所有截图准备超时的触发原因。若重复出现截图错误，仍需核对页面加载和实际图片，不能保证自动处理成功。

## 视频播放报错后的线路恢复

当前选中的播放器出现“播放终止”“无法播放媒体”或“您可以尝试其他线路”等已识别错误，且提供公网线路单选按钮时，脚本先点公网1，等待约 8 秒核对；未恢复再点公网2。公网1禁用或不可用时直接尝试公网2。只操作该播放器错误层内的线路按钮，不点页面其他同名选项。

只有错误层已消失、媒体没有错误且播放时间实际向前推进，才判断线路恢复。仅显示正在播放或缓冲状态正常不算成功；恢复后仍等视频实际结束及平台任务点结算。每条线路在本轮最多尝试一次，换了媒体地址也不会反复重置次数。没有可用线路或两线均失败时，AI 模式接续每章一次自动恢复，再失败记录待复核；无 AI 模式直接记录并继续其余任务。

手动停止、夜间休息或弹题出现时不继续切线；显式点击“开始自动”可重新尝试，自动恢复不会重置线路次数。跨域播放器也须先由当前课程页授权接管。没有适配的错误层、需要额外登录或平台没有提供线路时，不能保证恢复，不会伪造任务完成。

## 1. 脚本的执行顺序

面板状态框下方常显前台运行提醒。建议选中正在学习的课程标签、保持窗口可见、不最小化、不让电脑休眠。后台计时器可能被浏览器节流，导致弹题、判题后的“继续学习”或切章检查延迟；这不一定是 AI 断连。专题阅读打开独立标签后，请将阅读标签保持前台并有焦点。出现卡住时的核对与恢复步骤见 [README 的前台运行说明](../README.md#开始前记住这几件事)。

脚本在浏览器中的学习通课程页运行。需要 AI 作答时，会调用设置中指定的服务商，或连接电脑上运行的 Codex。

页面响应超时不累计已观察到的后台停留，切回前台先重新核对判题结果、对应任务点及导航状态，并留出至少 3 秒检查。视频意外暂停会触发续播检查，遇到弹题、已结束视频、手动停止或夜间休息则不播放。此调整不屏蔽可见性事件、不延长 API 请求超时，也不增加专题有效阅读时间；浏览器节流仍可能延迟操作，平台是否记入学习进度由平台决定。

```text
打开课程 → 选择运行模式
不接入 AI：直接开始自动（题目记录跳过）
接入 AI：保存 AI 设置 → 测试 AI → 开始自动
    ↓
清点当前页任务，等待必要内容加载
    ↓
所有视频逐个播放 → 视频弹题 → 继续学习
    ↓
本页文献逐个停留 30 秒并确认内部滚动到底
专题目录逐项前台停留 90 秒，多个入口依次处理
    ↓
本页检测：分析 → 填写 → 提交 → 确认 → 核对成绩
未全对且允许重做：读取反馈 → 确认重做 → 再作答
    ↓
复核本页任务 → 本章下一个学习步骤 → 重新清点
    ↓
本章可处理步骤完成，无法处理项已恢复重试并记录跳过 → 下一章

遇到异常 → AI 模式每章最多测试并重新开始一次；无 AI 模式不测试
仍失败 → 记录待复核、跳过本项 → 可识别检测/剩余任务 → 下一节
```

以下检测与测试恢复流程适用于 AI 模式；无 AI 模式不作答、不重做，直接记录无法处理项并继续。不同课程的页面结构可能不同。自动运行异常时，当前章节最多自动执行一次“测试 AI → 开始自动”。恢复后仍失败，就记录待复核并跳过无法处理的内容，优先继续可识别的检测和剩余任务，再下一节；遇到已识别的“本章还有任务点未完成”提示，可点击其中的“下一节”。跳过不会修改平台任务点，也不代表该项已完成。手动停止、预览 AI 答案和夜间休息不会触发自动重启；找不到可用导航或平台禁止前进时仍需人工接手。

## 3. 视频播放与倍速

- 自动模式会尝试播放当前识别到的视频，视频结束后进入本节检测或下一学习步骤。
- 可选 **1×（建议）、1.1×、1.2×、1.25×、1.5×、1.75×、2×、4×、8×、16×**，默认1×，所选速度会保存。
- 视频弹题出现时先答题，再恢复当前视频。后续视频动态插入的弹题会持续检测；父页面没有识别到时，由已授权子页面补充接管，避免父子重复作答。任务点变绿不代表当前视频真正结束：默认100%模式等待媒体结束事件；选择90%时内部按91%判断，并等待对应平台任务点确认完成，未确认就继续播放。脚本不会拖进度、伪造结束事件或修改平台任务标记；音频仍完整播放。一个视频结束后先清点剩余视频，不因第一个视频结束就进入检测；所有视频处理完才继续文件、专题和测验。未加载时长的播放器仍保留在清单中。
- 静音默认开启，可取消勾选；本页、内嵌页面和后续章节同步选择。停止或休息时修改静音只调整静音状态，不会启动已停止的媒体。
- 关闭静音后，浏览器若拒绝有声自动播放，脚本会暂停并提示手动播放或重新开启静音。
- 浏览器可能要求先手动点击一次播放。倍速是否生效、观看时长如何计算，以平台规则和播放器为准。
- 关闭页面、电脑休眠、网络中断、后台冻结都可能影响运行。脚本不能唤醒电脑或重新打开课程。

视频进度到头不一定等于任务点已结算。仅当媒体确认播放结束、对应视频任务点仍未完成、没有待处理弹题时，脚本先等 3 秒；仍未完成则最多点一次左下角“重播”按钮（圆形箭头），继续等待对应任务点变绿。按钮确实会触发重播，脚本不会刷新整页、拖进度或修改任务点；平台确认完成后会暂停本次恢复触发的播放，再处理剩余任务。自发现未结算起约 23 秒仍未完成、按钮不可用或状态不明时，自动测试 AI 并重新开始一次；同一视频不重复点重播。再次等待仍失败则记录跳过。停止、夜间休息、切章和媒体更换会阻止旧恢复操作；不会因为一个视频变绿就跳过本页其他视频。

即使平台显示视频任务点已完成，仍显示的视频弹题也可能需要处理后才能继续。

## 4. 视频中突然弹出的题目

脚本能识别已适配的视频单选、多选和判断题面板。

1. 读取题干和选项，向配置的 AI 请求答案。
2. 核对答案是否对应当前题目，再选中选项并检查选中状态。
3. 点击提交并等待平台反馈。
4. 答对后点击 **继续学习**，再恢复视频。
5. 已显示答对且有继续按钮时，优先继续，避免再次调用模型。

未答对时，脚本会读取错误提示和可用重试入口。即使没有单独“重试”按钮，只要原题仍可编辑、提交可用且没有强制回看要求，也可以改选后重新提交。会保留失败记录，避免重复尝试同一个答案；模型最多额外复核两次，仍重复时改用未提交候选并提示。候选耗尽、次数用尽或平台要求回看时，不绕过回看要求；恢复后仍无法处理会记录跳过。

如果刷新后保存着旧的“已提交”记录，但当前原题仍可编辑、没有判题中或结果，脚本会恢复作答。提交按钮第一次没有触发判题时，仅在选项未变化、仍无判题或反馈的条件下，等待约 2 秒后最多补点一次。仍无反馈则先自动测试并重启一次，再失败记录跳过；平台正在判题时只等待，不补交。

滚动页面把播放器移出视口，不会被当作题目已经更换。真正切章、隐藏或移除播放器、手动停止和重新开始时，会取消旧请求，防止迟到答案干扰当前题。

## 5. 章节学习检测与重做

当前支持 **单选、多选、判断，以及普通/课程 UEditor 填空和简答输入框**。填空按输入框顺序返回答案；简答只处理单个普通文本框。除上述已适配课程 UEditor 外的富文本、未知 iframe 编辑器、配对、拖拽、录音等控件仍需手动处理，无法确认输入框对应关系时不会强行填写。

开始写入前，脚本检查整组输入。已有内容、模型等待期间新填的内容以及之后的手动修改会保留，本次自动提交会取消。只有脚本自己写入且未被修改的文本，才允许在重试中替换。填空和简答答案不确定时不随机编造字符串；选择题仍按原来的低置信度策略处理。

- 自动填写后提交，并处理已适配的“确认提交”弹窗，再读取成绩。
- **第一次就全对不会额外重做。** 脚本先复核本页及本章其他学习步骤，全部完成才进入下一节。
- 未全对时，根据平台提供的重做入口和剩余次数决定是否重做，并处理“确认重做”窗口。
- 次数用尽或没有可用重做入口时，仍需通过任务完成核对；任务点未完成或剩余次数无法识别时先恢复一次，再失败记录跳过。
- 没有单独设置的无限重试；提交或重做后长时间仍显示旧页面会停止，避免循环点击。

结果页明确显示的正确答案会保存下来，供同一任务重做时使用。全对的答案也会记录，减少重复调用 AI。选项顺序变化时，脚本重新匹配文字或图片来源标识；题目或图片变化后，会检查旧答案是否仍适用。未在页面展示的正确答案无法读取。

### 没有参考答案时怎样重做

脚本会保存失败尝试的题目、选项、选择和得分，并按题目及选项内容比较。选项字母或题目顺序改变，不会被误认为换了一组答案；平台已确认正确的题目保持不变。只有整卷成绩时，也不会据此认定每题都错。

AI 会参考最近几轮已匹配的历史反馈重新作答。若候选仍与失败过的整组选择相同，最多再调用 AI 复核两次；仍重复时，会选择一个未提交过的组合，并说明这是尝试性调整，不能保证正确。提交前还会检查，拦截已记录的重复失败组合。

保留已确认答案后，如果其余可区分组合都已尝试，脚本会复核整页任务，仍受平台完成状态限制，无法确认完成时恢复一次，再失败记录跳过。额外 AI 复核可能增加接口费用。旧版本未保存的完整历史无法恢复，只能迁移仍有对应题目快照、可核对的最近失败记录。

## 填空题的处理规则

支持已适配的普通输入框，以及课程页“第1空、第2空……”的 UEditor 填空。先让文字接口按空位顺序给出答案，脚本填写并同步预览和提交字段，提交后读取实际得分。**“任务点已完成”不代表全对。** 未满分且平台显示可匹配的正确答案、允许重做时，按正确答案原文再填一次；不会为了换一个答案而随机编造文本。

多空答案必须能逐空对应；不按逗号随意拆分答案。没有参考答案时仍沿用原有历史得分复核规则，不保证满分。已有手动内容、只读输入框或无法可靠识别的编辑器会保留并记录；单个编辑器等待最多 4 秒，不会一直卡在填空题。**不接入 AI 时仍记录跳过题目，不会自动生成填空答案。**

## 文字 / 视觉模型分流、分批与能力测试

填空题属于文字题，纯文字填空使用文字接口；包含配图或公式时沿用图片题处理规则。文字和图片用途各选一个接口，可来自不同服务商，也可由同一个接口兼顾。用于文字/用于图片按钮显示当前选中状态；修改后重新测试。没有图片接口时记录跳过图片题，继续其他内容；同一测验含跳过题时不自动提交整页。接口失败不会自动切到其他服务商。

单页最多读取 256 题，按文字/图片分组后，文字每批最多 16 题、图片每批最多 8 题；题目文字较长时提前拆批。各批依次调用，避免同时发起大量请求。完全相同的截图在本批只发送一次，附带图片序号和题目标识，避免图片去重后串题。全部批次成功并通过校验后，才按原题目顺序填写；中途停止、题目切换或后续某批失败，都不使用已经返回的部分答案自动提交。单张内容过长或本批图片总量超过限制时仍需缩小范围。

“测试图片识别”读取当前分配给图片用途的已保存配置，把随机六位数字画成图片，文字提示中不提供数字。返回结果完全匹配才显示通过，失败仅说明本次未确认能力。测试可能计费；不代表复杂图片、公式或实际题目一定答对，也不代表所有账号都能调用该模型。修改配置后应重新测试；停止、夜间休息或切换运行模式会取消尚未完成的测试。

## 自定义兼容接口

服务商选择“自定义 / OpenAI 兼容”后，设置中显示独立[操作流程](CUSTOM_API.md)，包含第三方 / 自建接口、Ollama 等 22 种常见兼容工具、保存用途及排错说明。地址、模型 ID 和 Key 必须匹配同一家服务。

## 集中补做与脱敏诊断

运行结束后展开“跳过记录”，点击 **集中补做未完成章节**。脚本只选择同课程、班级和账号标识下，目录位置与标题仍一致的历史跳过记录。补做点击章节标题以触发平台的切章事件，已在目标章节时直接继续；打开失败会显示提示并导出固定的脱敏导航错误。点击前及队列每项开始前，重新核对当前目录；已有明确绿色完成标记的项移出待复核，不再重播。目录后来重新显示未完成数量时恢复待复核。标记冲突或未知状态不当作完成，实际任务仍进入页面实时核对。缺少账号标识时仍保存跳过记录，但需手动补做；无法证明归属的旧记录、目录已变动记录，以及提交/判题结果未确认项需要手动检查。手动停止或切章会取消队列，夜间休息时也取消本轮补做，避免无人确认时反复重试。

补做失败的章节仍保留待复核；处理过且未发现遗留项时标为已复核；平台目录显示完成时标为“目录已完成”，不等于检测已满分。提交或判题结果未知项仍要求手动检查。不替平台修改任务点，也不保证已获得学分。旧版本只有章节名的记录不会强行匹配到新目录。集中补做不覆盖原有的“当前章最多自动恢复一次”的运行限制。

**导出脱敏诊断** 会下载 JSON，包含固定错误分类、时间、HTTP 状态等少量信息，不包含 Key、题干、截图、课程地址、原始异常文本或接口响应。文件由用户自行检查后选择是否附到 Issue，脚本不会自动上传。

## 目录缓存与可选同源预读

脚本缓存当前章节目录，目录节点、标题或属性变化后重新读取。“同源章节预读”默认关闭，勾选后立即检查并显示结果，切换设置不停止当前学习；开始自动时也会重新检查。只对目录里实际存在、同课程同班级同账号的同源学习页链接发起普通 GET，不猜测接口参数。最多预读 4 个入口，缓存 60 秒，同一 URL 的并发请求合并，每次请求最多等 15 秒、读取 2 MB。停止、夜间休息、人工验证、页面退出或目录变化会取消预读。没有可靠链接的目录显示“不支持预读”，不会猜测地址或静默等待。

预读只解析分离文档中的卡片和 iframe 数量，不执行页面脚本、不加载其中媒体、不提取隐藏答案，也不根据预读内容跳过任务或标为完成。没有可靠链接、跨域或读取失败时照常使用实际页面。这是可选的只读页面结构准备，不代表实际导航提速；它不预读视频、不绕过平台学习时长要求。

## 6. 图片题与不确定答案

### 题干配图、图片选项和特殊字体

支持已适配章节题中的题干图片和纯图片选项。默认按题目内容自动分流：普通文字题只发文字；题干、选项中有图片，或使用特殊字体、公式等需要看图的内容时才截图。可分别配置文字模型和图片题专用视觉模型。需要给图片用途指定支持图片输入的接口；若只有一个可看图的接口，可同时把它用于文字和图片。

脚本先加载题目图片，再生成截图。可在面板展开预览，确认图片是否完整。生成截图时使用页面副本，不改动原题。未配置可用视觉模型时，图片题按恢复和跳过策略处理；图片加载失败或题目变化时，也会取消旧结果。

字体加载等待超过 8 秒，或截图生成超过 20 秒时，会停止这次提交并显示提示，避免一直停留在“正在读取”。这两个等待上限与单题图片准备的 30 秒预算分别计算。

### 哪些情况会随机填写

自动提交模式下，模型响应通过格式校验后，**置信度低于 0.8，或模型返回 `readable=false`（无法可靠辨认），会随机选择答案**，并在面板标注。提交后依据平台反馈判断能否重做。

只有格式有效的模型结果才进入上述判断。连接失败、权限或余额错误、无效 JSON、未知选项，以及准备截图时的图片读取失败，不会触发随机提交。自动模式会按每章一次的上限测试并重启，再失败记录跳过；“预览 AI 答案”不自动恢复。“预览 AI 答案”也不会随机提交。

## 7. PDF、Word 与嵌入文献

识别到 PDF/Word 阅读入口或嵌入文档后，脚本会依次：

1. 打开或识别文献预览。
2. 停留 **30 秒**，显示倒计时，约 20 秒滚动至可识别的文档内部底部，不滚动课程目录或整张课程页。
3. 停留结束后，最多再用 8 秒核对内部滚动条是否稳定到底，再关闭脚本打开的预览；嵌入式文档按页面结构处理。
4. 继续本页剩余文件、专题或测验，复核当前页任务及本章其他学习步骤。所有步骤完成后才切章。

文献是否必修，只看它所属容器自身的任务图标，不借用旁边测验的图标。明确无任务点的拓展资料在处理后继续后续内容；即使内部滚动无法确认，也不消耗本章的 AI 恢复次数、不新增“未完成／待复核”记录。没有容器、无法确认有无任务点的资料仍按未知内容处理。历史待复核记录保留，脚本不会猜测并删除旧记录，也不会把可选资料标成平台已完成。

必修资料出错时，只针对当前文件恢复和授权；同页其他文件仍须分别处理。文献读取与后续检测加载分开核对，后续检测尚未就绪不会被算作文献读取失败。学习检测自己的黄色任务点是答题后要完成的对象，不是答题前必须已经完成的条件。

30 秒是固定停留时长，内部滚动确认可能额外等待。支持已识别的同源和跨域阅读器；跨域滚动需要阅读器中也启用脚本。无法控制或确认滚动到底时，显示原因，恢复一次仍失败会记录跳过，继续其余文件或检测。特殊预览器和自定义完成条件可能无法处理。**停留结束不保证平台任务点完成**，请以平台标记为准。此功能不将 PDF/Word 全文发送给 AI 做阅读总结。

### 专题阅读：“去阅读”与左侧目录

专题阅读与 PDF/Word 预览是两套流程。支持已识别的学习通专题门户和详情模板，脚本从当前页面读取完整目录，不绑定某本书、固定章节 ID 或目录数量；不代表任意外链阅读网站都能处理。

1. 点击“去阅读”，打开脚本持有的独立标签。
2. 依次打开目录项，等正文加载后，每项累计 **90 秒前台有效停留**。目录变黄只表示访问过，不作为计时完成依据。
3. 切到其他标签、窗口失焦、夜间休息或手动暂停时，不累计时间；页面重新可用后继续。休眠时间不会补算为阅读时间。
4. 保存已完成项和当前累计时间。阅读页刷新，或原课程刷新后重新接续时，可继续尚未完成的小节。
5. 全部目录项结束后，关闭本次打开的阅读标签；原课程页可见后优先检查本章检测，再下一章。无法自动回到前台时，请手动切回原课程标签。

原课程停止、切章或关闭时会终止其持有的阅读流程；提前关闭阅读标签会暂停，重新从原课程点击开始可接续。脚本不关闭其他原本打开的阅读标签。同页多个专题入口会依次处理；目录发生变化、正文未加载或新标签无法打开时，会暂停并提示。

这是正常打开页面和等待的流程，不调用平台时长接口，不伪造焦点或活动。平台是否记入时长、何时更新任务点，仍需按平台实际记录确认。

## 8. 未识别内容与弹窗处理

### 无法识别的内容

脚本先等待内容加载并复核本页任务。无法识别的必修任务、不可确认完成的文献、持续加载的播放器及未完成的任务标记，会先等待或尝试恢复。自动运行异常时，当前章节最多自动执行一次“测试 AI → 开始自动”。恢复后仍失败，就记录待复核并跳过无法处理的内容，优先继续可识别的检测和剩余任务，再下一节；遇到已识别的“本章还有任务点未完成”提示，可点击其中的“下一节”。跳过不会修改平台任务点，也不代表该项已完成。手动停止、预览 AI 答案和夜间休息不会触发自动重启；找不到可用导航或平台禁止前进时仍需人工接手。

### 已适配的弹窗

| 类型 | 自动行为 |
| --- | --- |
| 确认提交 | 点击弹窗提交，等待成绩 |
| 确认重做 | 点击确定，等待新的答题表单 |
| 当前章节还有任务点未完成 | 已记录跳过项后可确认“下一节”，继续后续章节；不修改平台完成标记 |
| 星小讲浮窗 | 根据内容及右上角控件特征识别，尝试关闭 |
| 视频答对后的继续学习 | 点击继续，再恢复视频 |

上述处理依赖已识别的页面结构。网站改版、出现新的弹窗样式或跨域限制时，可能需要更新脚本。

## 9. 每日休息时段

- 默认开启 **北京时间 23:00–次日 07:00** 休息，可取消勾选；当前没有自定义起止时间输入框。
- 进入休息时段后，停止自动操作、暂停脚本控制的视频、取消正在等待的请求，并关闭脚本打开的文献预览。
- 休息前正在自动运行的任务，07:00 后尝试恢复；夜间点击开始可以预约恢复。
- 手动点击停止会取消恢复预约。
- 需要电脑、浏览器、页面和网络持续可用。关闭页面或电脑休眠后不能保证准点执行。

取消本地等待不能保证服务商撤销已收到的请求或退回费用。

## 10. 多模型接入与设置说明

内置预设包括 **OpenAI、Claude、Gemini、DeepSeek、小米 MiMo、Kimi / Moonshot、智谱 GLM、通义千问 / 百炼、豆包 / 火山方舟、硅基流动**，另有自定义兼容接口和可选本地 Codex。

选择预设后，脚本会填写协议和基础地址，并显示该服务商的模型下拉列表。没有所需模型时选“没有我要的模型，手动填写”；旧自定义 ID 会保留。目录有核对日期，不代表每个账号都可调用，具体范围见[模型目录与推理设置](MODELS.md)。密钥和余额需要自行准备。

| 设置 | 含义与建议 |
| --- | --- |
| 服务商 | 选择预设，更换后填写对应模型和密钥 |

| 用于图片 | 指定图片接口，实际图片题才发送截图；没有图片接口则记录跳过 |
| 发送 JSON 模式参数 | 仅在接口支持时开启，不支持可能报 400 |

保存后密钥输入框清空显示；同一服务商、协议和地址下留空保存可保留原密钥。更换目标后要重新输入密钥，避免旧密钥发往其他主机。

使用 **API 模式**时，无需安装 Node.js 或启动本地服务。使用 **Codex 模式**时，需要完成电脑上 CLI 的登录，并保持连接服务运行。PowerShell 中运行 `npm run start:codex`，用方向键和回车选择模型及推理强度后启动；上次选择保存在本机，下次作为菜单初始选项。列表来自 Codex CLI，只显示各模型返回的强度；目录可能来自缓存，不代表调用权限已经验证。Esc 或 Ctrl+C 可取消启动。更换模型时停止服务后重选，地址和连接码不变时无需重建面板配置。环境变量直启改用 `npm run start:codex:direct`；面板中的 API 设置不改变本地服务模型。步骤见 [安装教程](INSTALL.md)。

## 11. 费用与数据保存

- API 使用自己的账号额度，测试也可能计费。截图、长题目、高推理强度和多次重做可能增加用量。
- Codex 使用当前 CLI 登录账号，按该账号的规则消耗额度。
- 题干、选项、启用的截图和必要的历史反馈会发往用户配置的接口。
- 设置、密钥和任务记录保存在脚本管理器存储中，包括重做状态、已知答案、文献记录及专题目录进度。专题接续还会保存阅读目标地址和本地任务关联，不汇集到云端共享题库。
- 没有作者服务器、遥测或自动问题上报。反馈截图需用户手动选择、脱敏、提交。
- 密钥存储不是加密保险箱，不要分享脚本管理器存储导出。

更多数据流说明见 [安全与隐私](SECURITY.md)。

## 12. 卡住或停止时怎么办

先查看面板具体提示。处理后重新开始；更改 AI 配置后先保存并测试。

| 现象 | 建议处理 |
| --- | --- |
| 无法连接本地服务 | 仅 Codex 模式需要本机服务，检查是否运行、地址和连接码是否一致 |
| 401 / 403 | 检查密钥、账号权限、模型授权和地区条件 |
| 400 / 404 | 检查协议、地址、模型 ID；关闭不支持的 JSON 或推理参数 |
| 429 | 检查余额或限流情况，稍后手动重试 |
| 视频题一直显示 | 看是否调用失败、继续按钮未识别，附脱敏结构或截图反馈 |
| 提交或重做超时 | 检查新样式确认窗口、网络和页面更新情况，避免反复点耗费机会 |
| 图片读取失败、题目乱码 | 检查截图预览、视觉模型和图片加载 |
| 文献任务点未完成 | 核对平台实际阅读要求，必要时手动处理 |
| 完全没反应 | 检查停止状态、休息时段、脚本权限和浏览器冻结；停用同类脚本后刷新 |

## 本地 Codex 的 GPT 主题与一键测试

本地 Codex 连接使用既有 GPT 主题、图标和人物。点击一次“测试 AI”先检查服务，随后实际调用启动菜单里选中的模型：文字随机简单加法和已选图片用途的随机六位数字 PNG 分别验证，正确且置信度足够才显示通过，不把仅健康检查当成模型回复。结果显示服务选中的模型与推理强度；单项失败保留另一项结果。测试消耗模型用量，可停止取消，禁止重复点击且保留夜间休息。图片测试复用原有 /solve，兼容能正常答题的旧版本地服务，无需仅为测试更换连接码；独立图片测试按钮仍保留。


## 连接反馈与自动主题

本地 Codex 需要启动 CLI 并依次验证已选文字和图片，耗时会叠加；没有同条件 API 对比，不承诺固定耗时或本地一定更慢。测试按钮下立即显示耐心等待说明、当前阶段、已通过项及每秒更新的已用时间；完成、失败或停止后清理提示。既有请求与超时保持，未增加模型调用。

文字接口测试通过后自动匹配当前已支持的 AI 主题，本地 Codex 对应 GPT；此前手动选择默认、奶龙或奶蛙也会切换。测试后仍可手动选择其他外观，直到下次文字测试通过；测试失败不会强制开启主题，图片用途不改变主主题。GPT 开关图标单独加深、放大，品牌图标和人物资产保留。

1.5.4：修复专题阅读完成后，无AI模式在满分结果页等待内容稳定后未继续导航的问题。

## 1.5.13 简答题设置与暂存测验

简答题设置整块可折叠，默认收起，三种互斥选择及持久化保持。成功暂存的整份测验记录在“跳过记录”下方的“暂时保存的测验”，不再计入跳过。按钮只打开原章节、学习步骤和测验，不触发自动答题或提交；目录变化或测验归属不明时说明未能精确定位。旧版本可识别的saved记录迁入列表，旧记录若缺具体测验标识仅能返回章节。真正跳过、保存结果不明及其他失败仍留在跳过记录。

题干单题上限为64000字符，超限报出题号、实际长度和上限，不截断正文。长篇文字阅读材料分批时随同后续题目传入，作为上下文而非额外待作答题。模型上下文与接口限制仍以实际返回为准。暂存不等于平台完成或成绩，真实课程结果需单独核对。


### 讨论详情页处理状态（本地1.5.14）
脚本自动打开的讨论详情页左下角固定显示当前处理阶段和实际已用时：读取题目、准备图片、等待 AI、调整回复、填写和确认发表。等待较久时说明仍在等模型接口；不显示虚构百分比。暂停、未发表、发表结果不明会显示相应原因；发表后仍需返回课程确认平台任务点。提示不遮挡点击、不读入老师题目或学生回复，也不会触发重新发表。仅手动打开且没有有效自动会话的讨论页不显示处理提示。


本候选增量保留独立待批阅/答案语言修补：平台明确显示“待批阅”时，记录已提交待批阅，保留答案，不刷新、重做或重交，也不假定0分或满分；继续同章其它可识别任务。填写语言优先遵循明确要求与翻译目标，其次题干语言；中文讲解与英文填写答案分开。明显不符时每批最多纠正一次，仍不符不回填不交。相关验证仍为模拟页面及接口，不证明真实成绩。
