# 多服务商 API 版教程

安装 `dist/xuexitong-api.user.js`。本版与其他版本共用相同任务点、题型、图片与人工输入保护；首次打开使用 OpenAI 预设，面板仍可选择全部服务商。它不是 Codex/WorkBuddy 账号额度连接，使用的是服务商 API Key 和对应账户用量。

## 配置一次即可

1. 下载完整项目，按 [用户教程](USER_GUIDE.md) 将脚本导入油猴，刷新课程页。
2. 面板 → 接口 → 添加 / 编辑接口。选择服务商后，协议和 Base URL 会自动带入已有预设。
3. 填写服务商 API Key、账号实际可用的完整模型 ID；代理平台需要填写该平台自己的地址和模型 ID。
4. 选择用途：文字题、图片题，或两者兼用。保存，再点击“测试 AI”。图片用途必须使用该模型实际支持的图片输入接口。
5. 先运行预览，确认题干、图片和答案完整，再按需要开始处理未完成任务点。

API 版不需要启动本项目本地服务；如果使用本机 API 网关，网关本身仍需按其说明运行。不要把本地 Codex/WorkBuddy 连接码当成服务商 API Key。

## 已有适配

- **OpenAI**：Responses、Chat Completions。
- **Claude / Anthropic**：Messages。
- **Google Gemini**：generateContent。
- **DeepSeek、小米 MiMo、Kimi / Moonshot、智谱 GLM、通义千问 / 百炼、豆包 / 火山方舟、硅基流动**：项目各自的预设与协议处理。
- **自定义 / OpenAI 兼容**：自行填入提供方的 Base URL、模型和 Key。

完整预设与验证日期见 `src/ai.js`、`src/models.cjs` 和 [保留的服务商说明](PROVIDERS.md)。预设支持某家服务，不代表这家所有模型都支持图片、思考强度或结构化输出；模型 ID、权限和参数应按提供方当前文档核对。

## 混合使用不同 AI

可以把 DeepSeek 等配置为文字接口，把另一家已验证的视觉模型配置为图片接口。也可以把 Codex 或 WorkBuddy 作为其中一个用途：本版本仍然保留这两个本地适配器。安装文件是首次配置入口，不限制后续切换。

修改模型后先用默认思考设置测试，确认服务端接受再开启支持的思考强度。HTTP 401 通常检查 Key；404 检查地址和模型；429 检查速率和用量；答案格式错误先预览，不能删掉校验后强行提交。

本教程参考保留的 [自定义 API 说明](CUSTOM_API.md)、[服务商说明](PROVIDERS.md) 和源码中的实际适配；不包含任何人的 API Key。
